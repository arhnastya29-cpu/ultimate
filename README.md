# ULTIMATE — личная система эффективности


Раньше приложение называлось LifeOS; папка `lifeos` и внутренние ключи хранилища оставлены
прежними, чтобы уже накопленные данные не потерялись.
Локальное веб-приложение без сборки и без внешних зависимостей. Все данные хранятся
в браузере (IndexedDB) на этом компьютере; резервную копию можно выгрузить в JSON
в разделе «Настройки» и импортировать на другом устройстве.

## Запуск

Дважды кликните `start.command` — поднимется локальный сервер и откроется
`http://127.0.0.1:8765/` в браузере. (При первом запуске macOS может спросить
разрешение; если файл не открывается — ПКМ → «Открыть».)

Либо из терминала:

```bash
cd ~/Desktop/lifeos && python3 -m http.server 8765 --bind 127.0.0.1
```

Открыть с телефона в той же Wi‑Fi сети: запустите сервер с `--bind 0.0.0.0`
и откройте `http://<IP вашего Mac>:8765/`. Данные на телефоне будут свои
(отдельный браузер) — переносите их через экспорт/импорт.

## PWA: установка на телефон и офлайн

ULTIMATE — прогрессивное веб-приложение (PWA): `manifest.webmanifest`, иконки в `icons/`,
service worker `sw.js`, регистрация в `src/pwa.js`. После первого открытия оболочка
приложения лежит в кэше и работает без интернета; данные по-прежнему в IndexedDB.

- **iPhone (Safari):** «Поделиться» → «На экран Домой».
- **Android / Chrome / Edge:** кнопка «Установить» в «Настройках» приложения или иконка
  установки в адресной строке.
- **Mac (Safari):** Файл → «Добавить в Dock». Chrome: меню → «Установить ULTIMATE».

Для установки с телефона приложение должно быть доступно по HTTPS (например, GitHub Pages)
или по `localhost`. По IP вида `http://192.168…` service worker не запустится.

**После любого изменения файлов** поднимите `VERSION` в `sw.js` (`lifeos-v1` → `lifeos-v2`),
иначе установленные копии продолжат показывать старую версию. Новый файл в `src/` нужно
добавить и в список `APP_SHELL` там же.

## Публикация на GitHub Pages

```bash
git init -b main && git add . && git commit -m "ULTIMATE"
git remote add origin https://github.com/ЛОГИН/lifeos.git && git push -u origin main
```

В репозитории: Settings → Pages → Source: Deploy from a branch, `main`, `/ (root)`.
Через пару минут приложение доступно по `https://ЛОГИН.github.io/lifeos/`. Все пути в
проекте относительные, поэтому подпапка `/lifeos/` не требует настроек.

## Синхронизация между устройствами

В «Настройках» есть блок «Синхронизация»: придумайте пароль и введите его на каждом
устройстве. Данные шифруются паролем ещё на устройстве и хранятся в облаке (Supabase,
таблица `vaults`) в нечитаемом виде. Синхронизация идёт сама после каждого изменения,
при открытии приложения и при появлении сети. Если забыть пароль, облачную копию
прочитать нельзя; локальные данные останутся, можно задать новый пароль.

## Как устроено (с версии v21)

**Одна запись — везде.** Задача от CEO, обещание человеку, задача проекта — всё это одна модель задачи
(`tasks`) со связями: человек, проект, цель, источник. Рекомендации CEO, идеи, итоги встреч — одна модель
заметки (`notes`) с типом. Поэтому Shadow, План, календарь, карточка человека и проект показывают одни и те же
записи, а не свои копии. Старые данные переносятся автоматически при первом запуске (см. `docs/REDESIGN.md`).

**Кнопка «+ Записать»** (на телефоне — в центре нижней панели, на компьютере — в меню слева или клавиша `N`):
сначала текст, тип подбирается сам («созвон 15:30» → событие, «кофе 350 ₽» → расход, «выпила 500 мл» → активность),
контекст берётся из открытого раздела (в Shadow — задача от CEO, в карточке человека — с этим человеком, в проекте — в проект).

**Навигация.** На телефоне: Сегодня · План · «+» · Работа · Ещё. «Работа» открывает проекты, людей и Shadow с переключателем
сверху. На компьютере разделы собраны в группы (Основное, Работа, Знания, Личное, Ресурсы), группы сворачиваются.
В «Настройках → Интерфейс» есть наборы модулей (Минимальный, Работа, Здоровье, Полный) и управление каждым разделом:
в меню, скрыт из меню, выключен; можно закрепить свой раздел третьей вкладкой.

**Тон.** По умолчанию нейтральный: без «чемпион», без цитат. В настройках можно включить поддерживающий или деловой
тон и послания (рекомендации CEO с пометкой «цитата»).

**Настройка страниц.** Блоки по-прежнему можно перетаскивать и скрывать, но это спрятано в меню «•••» на каждой странице,
а стандартные экраны сделаны так, чтобы настраивать их не требовалось.

## Помощник на Claude

Кнопка-молния появляется только когда в «Настройках» задан ключ Claude (или ⌘J, или из палитры ⌘K). Помощник видит
выжимку всех разделов и по просьбе записывает задачи, заметки, обещания и события в общие модели. Ключ хранится только
на устройстве. Платите за использование: вопрос на Opus 5.5 стоит около 3–5 центов, на Haiku 5.5 — меньше цента.

## Разделы

| Страница | Что внутри |
|---|---|
| Сегодня | следующее событие, фокус дня (до трёх задач) со строкой быстрого добавления, привычки, компактный чек-ин («Как вы сегодня?» + сон/энергия/настроение/уверенность по раскрытию), что требует внимания, вечерняя рефлексия, карточки только используемых модулей |
| План | вкладки: Сегодня (задачи дня с полоской недели), Неделя (календарь: события с повтором, задачи, дедлайны, ожидания), Все задачи (инбокс, ближайшие, бессрочные, «жду от других»), Цели (+ Визуализация) |
| Проекты | активные проекты с прогрессом из задач, следующие действия, дедлайны, проекты без активности; страница проекта: стримы, задачи, заметки, журнал |
| Люди | лёгкий CRM: карточка человека с обязательствами в обе стороны, последним контактом, следующей встречей, заметками |
| Shadow | рабочее представление по CEO: обязательства (его задачи и «жду от него»), встречи и их итоги, рекомендации и заметки; одна кнопка «Записать» |
| Заметки | единая лента: заметки, идеи, рекомендации, итоги встреч, инсайты; источники (книги, статьи, подкасты); универсальный поиск; перенос в базу знаний |
| База знаний | свои разделы со страницами: разметка, теги, поиск, ссылки [[между страницами]] |
| Привычки | сегодняшние привычки, неделя, серия; статистика по раскрытию; привычки могут выполняться автоматически из воды, тренировок, занятий, сна, шагов и закрытых задач |
| Рефлексия | быстрый режим (настроение + главное событие) и полный (что хорошо / улучшить / благодарность / инсайт), недельные обзоры |
| Обучение | «Сейчас» (активный материал, таймер, последние занятия), материалы, области, карточки, статистика |
| Здоровье, Тренировки, Питание, Сон, Финансы | как раньше, но без нулевых карточек: список и ввод сверху, аналитика ниже |
| Настройки | имя, тема, нормы, тон и послания, модули и навигация, помощник, синхронизация, экспорт/импорт |

**Командная палитра:** `⌘K` (или `Ctrl+K`) — переход по разделам, «Записать…», быстрые записи («вода 300», «занятие 45»), смена темы.

Горячие клавиши: `N` — записать; `g` затем буква (`t` — Сегодня, `p` — План, `h` — Привычки, `l` — Обучение, `n` — Питание, `w` — Тренировки, `s` — Сон, `f` — Финансы).

## Структура кода

- `index.html` — оболочка
- `src/app.js` — роутер по хэшу, боковое меню, перерисовка при изменении данных
- `src/db.js` — хранилище (IndexedDB), коллекции и настройки
- `src/ui.js` — помощники: даты, иконки, формы, модалки, графики (столбцы и точки получают `data-tip` для тултипов)
- `src/fx.js` — эффекты: счётчики чисел, анимация прогресса, тултипы, палитра ⌘K, конфетти за закрытый день
- `src/model.js` — общая доменная логика (повестка дня, прогресс, авто-привычки, CEO, тон)
- `src/migrate.js` — перенос старых коллекций в единые модели
- `src/capture.js` — окно «Записать»
- `src/pages/*.js` — по модулю на раздел; стили страниц в `src/css/*.css`
- `docs/REDESIGN.md` — аудит, карта миграции и журнал реорганизации
- `SCHEMA.md` — схема данных и правила для новых страниц

## Локальная модель на вашем Mac (`ollama/`)

Помощник может думать локальной моделью вместо Claude: бесплатно, без интернета, данные не покидают компьютер.
На Mac установлена Ollama (`/Applications/Ollama.app`) и модель Qwen 2.5 14B. Чтобы модель запускалась сама
при входе в Mac и была доступна приложению в браузере, один раз дважды щёлкните `ollama/autostart.command`.
В «Настройках → Помощник» выберите «Локальная модель на этом Mac» и нажмите «Проверить».
На главной появится карточка «Совет на сегодня», а кнопка-молния откроет чат с действиями (задачи, заметки,
события записываются в приложение). На телефоне локальная модель недоступна: там помощник работает через Claude по ключу.

## Сигналы: новости из ваших источников (`src/signals.js`, `src/pages/signals.js`)

Раздел «Сигналы» (группа «Знания») собирает записи из выбранных вами источников и делает по ним сводку помощником.
- **Источники.** Вставьте адрес сайта (ленту приложение найдёт само), адрес RSS/Atom/JSON-ленты, ссылку на
  публичный Telegram-канал или `@канал`. Источник можно переименовать, поставить на паузу, удалить.
- **Лента.** Записи по дням, фильтры «Непрочитанные / Все / Сохранённые» и по источнику. У каждой записи:
  открыть, сохранить, в заметки, в задачу, прочитано. Непрочитанные старше 14 дней (настраивается) удаляются,
  сохранённые остаются. Лента обновляется сама при открытии раздела не чаще раза в час и по кнопке «Обновить».
- **Сводка.** Кнопка «Сводка» просит помощника (локальную модель или Claude) собрать «Главное / Ещё заметить /
  Что это значит для меня» по записям за сутки (период настраивается). В поле «Что мне важно» перечислите темы —
  они пойдут в сводку первыми. Сводка сохраняется, её можно записать в заметки; выдержка показывается на главной.
- **Разметка.** После обновления ленты модель (локальная или Claude) относит каждую новость к теме из вашего
  списка (по умолчанию: Политика, iGaming, Регуляция, Апдейты, Идеи бизнесов, Рынок, AI, Другое — меняется во
  вкладке «Сводка»), ставит важность («важно» / обычная / «фон») и склеивает повторы одного события из разных
  источников («+2 похожих»). В ленте — фильтр по темам, важное выше; сводка строится без повторов, важное первым.
- **Как загружаются ленты.** Браузер не умеет читать чужие сайты напрямую, поэтому ленты идут через «мост».
  Самый надёжный — локальный сервер ULTIMATE: `start.command` теперь запускает `serve.py`, который отдаёт файлы
  приложения и загружает ленты (`/__fetch/<метка>?url=…`, слушает только 127.0.0.1). На сайте GitHub Pages и на
  телефоне используется запасной путь — публичные CORS-прокси (allorigins, codetabs, rss2json): они видят только
  адреса лент, но бывают недоступны. Поэтому новости надёжнее читать в приложении, открытом через `start.command`.

## Чаты: переписка Telegram (`tg/`, `src/tg.js`, `src/pages/chats.js`)

Раздел «Чаты» (группа «Работа») показывает, кто ждёт вашего ответа, что вы обещали и что просят вас, плюс
короткую сводку за день; в чате помощника можно спрашивать «о чём договорились с…». Работает только на Mac,
где запущен `start.command`: сообщения забирает `tg/collect.py` (библиотека Telethon, официальный клиентский
API Telegram) от вашего имени и хранит в `tg/data/messages.json` за 14 дней. Каналы и боты пропускаются.
Ключи (`tg/config.json`), вход (`tg/ultimate.session`) и сообщения в репозиторий и в синхронизацию не попадают
(см. `.gitignore`). Разбор делает локальная модель; отправка переписки в Claude требует явной галочки.

Подключение: один раз дважды щёлкнуть `tg/login.command` — он попросит api_id и api_hash с my.telegram.org,
затем номер телефона и код из Telegram, и соберёт сообщения. В разделе чаты можно исключать из разбора.

## WHOOP: сон, восстановление, нагрузка (`whoop/`, `src/whoop.js`)

Данные WHOOP (API v2) забирает локальный сервер на Mac и записывает в базу: часы сна, отбой и подъём — в «Сон и
энергия» (оценку качества и заметки вы ставите сами), recovery, HRV, пульс покоя, фазы сна, дневная нагрузка —
в коллекцию `whoopDays` (карточка на главной и в разделе сна, помощник видит их в контексте), тренировки — в
«Тренировки» с пометкой WHOOP. База синхронизируется, поэтому на телефоне цифры тоже есть.

Подключение (один раз): в developer-dashboard.whoop.com создайте команду и приложение, отметьте права на чтение,
адрес возврата `http://127.0.0.1:8765/__whoop/callback`; Client ID и Client Secret вставьте в `whoop/config.json`
(образец `whoop/config.example.json`); в Настройках → WHOOP нажмите «Подключить WHOOP» и разрешите доступ.
Ключи, токены и данные остаются в папке `whoop/` и не попадают в репозиторий. Обновление — автоматически при
запуске на Mac раз в три часа или кнопкой в Настройках; первый сбор берёт 30 дней, кнопка «За 90 дней» — глубже.
