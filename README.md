# ULTIMATE — личная система эффективности


Раньше приложение называлось LifeOS; папка `lifeos` и внутренние ключи хранилища оставлены
прежними, чтобы уже накопленные данные не потерялись.
Локальное веб-приложение без сборки и без внешних зависимостей. Все данные хранятся
в браузере (IndexedDB) на этом компьютере; резервную копию можно выгрузить в JSON
в разделе «Настройки» и импортировать на другом устройстве.

## Запуск

Дважды кликните `start.command` — поднимется локальный сервер и откроется
`http://127.0.0.1:8765/` в браузере. (При первом запуске macOS может спросить
разрешение; если файл не открывается — ПКМ → «Открыть».)

Либо из терминала:

```bash
cd ~/Desktop/lifeos && python3 -m http.server 8765 --bind 127.0.0.1
```

Открыть с телефона в той же Wi‑Fi сети: запустите сервер с `--bind 0.0.0.0`
и откройте `http://<IP вашего Mac>:8765/`. Данные на телефоне будут свои
(отдельный браузер) — переносите их через экспорт/импорт.

## PWA: установка на телефон и офлайн

ULTIMATE — прогрессивное веб-приложение (PWA): `manifest.webmanifest`, иконки в `icons/`,
service worker `sw.js`, регистрация в `src/pwa.js`. После первого открытия оболочка
приложения лежит в кэше и работает без интернета; данные по-прежнему в IndexedDB.

- **iPhone (Safari):** «Поделиться» → «На экран Домой».
- **Android / Chrome / Edge:** кнопка «Установить» в «Настройках» приложения или иконка
  установки в адресной строке.
- **Mac (Safari):** Файл → «Добавить в Dock». Chrome: меню → «Установить ULTIMATE».

Для установки с телефона приложение должно быть доступно по HTTPS (например, GitHub Pages)
или по `localhost`. По IP вида `http://192.168…` service worker не запустится.

**После любого изменения файлов** поднимите `VERSION` в `sw.js` (`lifeos-v1` → `lifeos-v2`),
иначе установленные копии продолжат показывать старую версию. Новый файл в `src/` нужно
добавить и в список `APP_SHELL` там же.

## Публикация на GitHub Pages

```bash
git init -b main && git add . && git commit -m "ULTIMATE"
git remote add origin https://github.com/ЛОГИН/lifeos.git && git push -u origin main
```

В репозитории: Settings → Pages → Source: Deploy from a branch, `main`, `/ (root)`.
Через пару минут приложение доступно по `https://ЛОГИН.github.io/lifeos/`. Все пути в
проекте относительные, поэтому подпапка `/lifeos/` не требует настроек.

## Синхронизация между устройствами

В «Настройках» есть блок «Синхронизация»: придумайте пароль и введите его на каждом
устройстве. Данные шифруются паролем ещё на устройстве и хранятся в облаке (Supabase,
таблица `vaults`) в нечитаемом виде. Синхронизация идёт сама после каждого изменения,
при открытии приложения и при появлении сети. Если забыть пароль, облачную копию
прочитать нельзя; локальные данные останутся, можно задать новый пароль.

## Помощник на Claude

Кнопка-молния справа внизу (или ⌘J) открывает чат. Помощник видит выжимку всех разделов
и отвечает по делу, а по просьбе записывает задачи, привычки, заметки Shadow, журнал проекта
и дневник. Нужен ключ с platform.claude.com, он вводится в «Настройках» и хранится только
на устройстве. Платите за использование: вопрос на Opus 5.5 стоит около 3–5 центов,
на Haiku 5.5 — меньше цента.

## Разделы

| Страница | Что внутри |
|---|---|
| Сегодня | дашборд: задачи дня, привычки, питание, сон, самочувствие, тренировка, обучение, финансы, подсказки «что не сделано» |
| Цели и задачи (+ Визуализация) | задачи по дням с приоритетами и повторами, инбокс, просроченные; цели с ключевыми результатами и дедлайнами; недельный обзор |
| Проекты | Карточки проектов и страница проекта: стримы (направления), задачи внутри стримов, готовность, дедлайн, заметки, журнал событий |
| Shadow | Работа с CEO: его задачи со сроками и результатом, рекомендации и заметки-наблюдения, поиск |
| Привычки | ежедневные привычки, серии, недельная сетка, история за 12 недель |
| Рефлексия | дневник дня (что прошло хорошо / что улучшить / благодарность / инсайт), настроение, недельные обзоры |
| Обучение | области (психология, история, менеджмент, лидерство, эмпатия, английский), материалы с прогрессом, журнал занятий с таймером, карточки английского с интервальным повторением |
| Заметки | Саммери, мысли и цитаты из книг, статей, подкастов, видео и курсов в одном месте: источник, теги, поиск, лента или группировка по источникам |
| Здоровье | ежедневное самочувствие, вес, симптомы, медицинские дела, лекарства/БАДы, анализы с референсами и графиками |
| Тренировки | журнал тренировок с упражнениями и подходами, шаблоны, личные рекорды, прогресс по упражнениям |
| Питание | калории, белки/жиры/углеводы по приёмам пищи, библиотека продуктов, вода, шаги, недельная сводка |
| Сон и энергия | время отбоя/подъёма, часы, качество, энергия, долг сна, инсайты |
| Финансы | доходы/расходы по категориям, бюджеты, цели накоплений, тренд за 6 месяцев |
| Настройки | имя, тема, дневные нормы, экспорт/импорт данных |

**Командная палитра:** `⌘K` (или `Ctrl+K`) — переход по разделам, быстрые записи прямо из строки («вода 300», «занятие 45», любой текст → задача на сегодня или заметка), смена темы.

Горячие клавиши: `g` затем буква (`t` — Сегодня, `g` — Цели, `h` — Привычки, `l` — Обучение, `n` — Питание, `w` — Тренировки, `s` — Сон, `f` — Финансы).

## Структура кода

- `index.html` — оболочка
- `src/app.js` — роутер по хэшу, боковое меню, перерисовка при изменении данных
- `src/db.js` — хранилище (IndexedDB), коллекции и настройки
- `src/ui.js` — помощники: даты, иконки, формы, модалки, графики (столбцы и точки получают `data-tip` для тултипов)
- `src/fx.js` — эффекты: счётчики чисел, анимация прогресса, тултипы, палитра ⌘K, конфетти за закрытый день
- `src/pages/*.js` — по модулю на раздел
- `SCHEMA.md` — схема данных и правила для новых страниц
