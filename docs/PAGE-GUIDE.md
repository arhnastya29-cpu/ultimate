# Правила перестройки страниц (для всех, кто правит src/pages/*.js)

Контекст: docs/REDESIGN.md. Приложение без сборки (ES-модули), русский интерфейс, пользователь — не технарь.

## Что обязательно
1. **Единые модели** (`src/model.js`). Не читать и не писать `shadowTasks`, `shadowNotes`, `commitments`, `contacts`, `ideas`, `books`: они мигрированы в `tasks` и `notes`. Задача: `personId`, `source` (manual|ceo|promise|project|meeting|assistant), `direction` (mine|theirs — «мне обещали»), `time`, `checklist`, `tags`, `result`, `receivedAt`. Заметка: `type` (note|idea|recommendation|meeting|insight|project-log), `personId`, `projectId`, `goalId`, `quote`, для идей `status/impact/effort`, для встреч `meetingKind/next`. Создавайте через `addTask({...})`, `addNote({...})`, `toggleTask(id)`, `setTaskDone(id)`; «что сегодня» — `agendaOn(d)`, `nextEvent()`, `upcomingDeadlines()`, `overdueItems()`; прогресс — `projectProgress(p)`, `goalProgress(g)`; привычки — `habitStatus(h, d)`, `setHabitCount()`, `habitAutoProgress()`; люди — `lastContactOf(id)`, `nextMeetingWith(id)`, `openTasksOfPerson(id)`, `notesOfPerson(id)`; CEO — `ceoPerson()`; чек-ин — `checkinOn/setCheckin/sleepOn/setSleepHours`. Если нужной функции нет — добавьте в `model.js` (это единственный общий файл, который можно дополнять; не меняйте существующие сигнатуры).
2. **Без нулевой статистики.** Карточки `.stat` с числами показываем только когда данные есть; вместо них строка `statLine([...])` из `ui.js` (возвращает '' если всё пусто). Если в разделе нет ни одной записи — `emptyAction({ text, action, label, second })`: одна фраза о пользе, одно главное действие, минимум места. Никаких фильтров, графиков и пустых областей в пустом состоянии.
3. **Порядок на телефоне:** заголовок → (компактный выбор даты/вкладки) → основной список → быстрое добавление → фильтры → аналитика (раскрываемая `<details class="acc">`).
4. **Одно основное действие** в шапке (`.page-head .actions`: один `.btn`, остальное — `btn secondary` или в меню `pageMenu([...])` из `ui.js`, которое рендерит кнопку «•••»; пункты — `{ label, action, icon }`, они приходят в ваш обработчик `[data-action]`). Пункт `{ label: 'Настроить страницу', action: 'customize', icon: 'sliders' }` обрабатывается глобально — добавьте его в меню, если на странице есть блоки `data-block`.
5. **Вкладки:** `tabs([['id','Название', count?], ...], active, 'data-tab')` из `ui.js`.
6. **Фильтры** — `.chips` (на телефоне переносятся строками, не обрезаются). Если фильтров больше 4 — на телефоне свернуть в кнопку «Фильтр» (`<details>`).
7. **Тон:** без «чемпион», без восклицаний в нейтральном тексте. Подбадривания только через `cheer()`/`habitCheer()` из `motivation.js` и только если вернулась непустая строка: `const c = cheer(); if (c) toast(c)`.
8. **Контракт страницы:** `export const title`, `export async function render(root, { params, navigate })`; разметка в `root.innerHTML = '<div>…</div>'`, обработчики через `on(root.firstElementChild, 'click', '[data-action]', …)`; локальное состояние — в переменных модуля; формы — `modal()/field()/formRow()`. Записи, которые должны появляться везде, — только через `model.js`.
9. **Стили страницы** — в новый файл `src/css/<page>.css` (подключается в index.html; не правьте `src/styles.css`, `src/app.js`, `src/db.js`, `index.html`, `sw.js`). Используйте существующие классы: card, list, list-item, pill, tag, chip, btn, icon-btn, field, form-row, grid-2, stack, section-title, stat-line, empty-act, tabs, kind-ico. Интерактивные элементы ≥ 44 px на телефоне (`min-height:44px`), `aria-label` у кнопок-иконок, видимый фокус.
10. **Доступность и темы:** всё должно работать в светлой и тёмной теме (цвета только через переменные), с клавиатуры.
11. **Проверка:** после правок откройте страницу в браузере (python3 -m http.server 8765 --bind 127.0.0.1 в папке проекта; адрес http://127.0.0.1:8765/#/<id>) при ширине 1280 и 375 и убедитесь, что нет ошибок в консоли. Данные тестовые заводите через интерфейс.
