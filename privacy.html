ULTIMATE — политика конфиденциальности

Privacy Policy · обновлено 24 ноября 2026

ULTIMATE — личное приложение для одного пользователя (его владельца). Оно не является сервисом для третьих лиц и не собирает данные других людей.

Какие данные обрабатываются

  • Записи, которые владелец вносит сам: задачи, заметки, привычки, дневник, питание, финансы.
  • Данные из подключённых владельцем сервисов, например WHOOP: сон, восстановление, пульс, нагрузка, тренировки.
  • Новости из выбранных владельцем источников и, по его решению, его собственная переписка в Telegram.

Где хранятся данные

  • На устройстве владельца, в хранилище браузера (IndexedDB) и в папке приложения на его компьютере.
  • При включённой синхронизации — в облачном хранилище в зашифрованном виде; ключ шифрования известен только владельцу и не передаётся на сервер.
  • Ключи доступа к внешним сервисам (WHOOP, Telegram, модели ИИ) хранятся только на компьютере владельца.

Передача данных третьим лицам

Данные не продаются и не передаются третьим лицам. Запросы к внешним сервисам (WHOOP, Telegram, источники новостей, модель ИИ) выполняются только по инициативе владельца и только для его собственного использования. Локальная модель ИИ работает на компьютере владельца; отправка данных в облачную модель возможна только по явному согласию владельца.

WHOOP

Приложение запрашивает у WHOOP доступ только на чтение (сон, восстановление, циклы, тренировки, профиль, измерения тела) и использует эти данные исключительно для показа владельцу в его собственном приложении. Доступ можно отозвать в любой момент в настройках приложения или в аккаунте WHOOP, после чего токены удаляются с компьютера владельца.

Удаление данных

Владелец может удалить все данные в любой момент: через настройки приложения, очистку данных сайта в браузере и удаление папки приложения на компьютере.

Контакт

Вопросы по этой политике — владельцу приложения через репозиторий проекта на GitHub.
